## 4. SQL 语句拼接缺陷（空列表导致非法 SQL）

| 接口 | 用例场景 | 报错信息 |
|---|---|---|
| `POST /api/Tag/GetTagPivotReportTagData` | 查询全部标签树(不限profile) | `Incorrect syntax near ')'`，定位在 `TagRepository.GetSubTagList(List<long> portfolioIds)` |

说明：该调用方式（`profileIds` 传空数组）在近90天真实生产流量中占比 100%，但传入当前测试账号后，服务端把空的 portfolioIds 拼进 SQL 的 `IN (...)`，生成了非法的 `IN ()`。只要某账号解析不出任何 portfolio，这个"查全部标签"的默认调用就会直接报错，属于真实缺陷。

来源用例目录：`single-api/mainapi/us/PacvueMainApi/Tag/task-2026-08-19-17-07-55/report.json`
